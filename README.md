# daml-assignment1-kpop-mvs
for DAML assignment1 

K-pop Music Videos Across Generations
**1. Project Overview**
This project explores the distribution of K-pop music videos (MVs) across different generations of K-pop.
The dataset consists of 33 official music videos released by K-pop groups from the 1st to the 5th generation. Each entry represents one music video.

**2. Research Question**
How are K-pop music videos distributed across different generations?

**3. Data Collection**
The data was manually collected from official YouTube channels of K-pop groups.
What counts as one item: 1 music video.
The dataset includes one selected music video for each group included in the sample.
The following information was recorded for each music video:
  MV title
  Artist name (only group)
  Original release year
  K-pop generation
  Main language
  Other language versions, where applicable
  Official YouTube URL
  Source and copyright information

**4. Inclusion and Exclusion Criteria**
Inclusion Criteria
  Official music videos released by K-pop groups.
  Videos with an identifiable original release year.
  Videos with an accessible official YouTube URL.

Exclusion Criteria
  Solo artists.
  Dance practice videos.
  Live performances and concert recordings.
  Fan-made videos.
  Unofficial lyric videos or re-uploads.
  Teasers and promotional videos.

**5. Dataset Description**
The dataset contains the following fields:
Field                     |              Description 
id                        |   Unique identifier for each music video (mv_001, mv_002...)
title                     |   Title of the music video 
artist                    |   Name of the K-pop group 
release_year              |   Original release year 
generation                |   K-pop generation (1st–5th) 
main_language             |   Main language of the music video 
mv_language_versions.     |   Other language versions, if applicable 
video_url                 |   Official YouTube URL 
source                    |   Original information source 
license                   |   Copyright or licensing information 

**6. Copyright and Data Ethics**
All music videos included in this dataset remain the property of their respective copyright holders.
This project only collects descriptive metadata and links to publicly accessible official YouTube videos.
No copyrighted video or audio content is redistributed or claimed as original material by this project.

All video content can be accessed through the original YouTube sources.
